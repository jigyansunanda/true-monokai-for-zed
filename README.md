<h1 align="center">
 True Monokai for <a href="https://zed.dev/">Zed</a>
</h1>

<p align="center">
  The original Monokai theme for Zed, faithfully recreating the classic color palette and contrast of the OG Monokai. No pro-variants, no re-interpretations. just Monokai as it was meant to be.
</p>

- **Editor/buffer:** [Ioskeley Mono](https://ahatem.github.io/IoskeleyMono/)
- **UI:** [Oxanium](https://fonts.google.com/specimen/Oxanium) *(suggested by [u/baturax](https://www.reddit.com/user/baturax/) in [r/ZedEditor](https://www.reddit.com/r/ZedEditor/))*
